# Demo recording script

Target length: two to four minutes. Record the final plugin in a clean
environment on every supported surface the portal asks you to demonstrate.

1. Show the Parallel directory listing and that the plugin is connected
   without an account or API key.
2. Run: `Find the official Parallel Search MCP documentation and explain how anonymous access works.`
3. Show that the response uses `web_search`, follows with `web_fetch` when the
   primary page is needed, and cites the official source.
4. Run a current-information prompt that requires multiple queries, such as:
   `What are the headline features in the latest stable Python release? Use official sources and cite them.`
5. Show a concise sourced answer and the tool activity.
6. State that both tools are read-only, have no custom UI, and operate on public
   web information.

Do not show internal dashboards, credentials, private logs, unpublished tool
metadata, or user data in the recording.
