# Initial release notes

Parallel provides anonymous, rate-limited public web search and page fetching
through a hosted MCP server. The plugin includes a focused web-research skill
that teaches ChatGPT and Codex when to search, when to fetch a primary page,
how to synthesize results with source links, and how to treat retrieved content
as untrusted data.

This is the initial OpenAI directory submission. It includes the `web_search`
and `web_fetch` tools and does not require a user account, API key, OAuth flow,
or demo credentials. It has no custom UI and performs no write or destructive
actions.
